# معاذ AI للتعليم

نسخة أولية قابلة للتشغيل محليًا كتطبيق ويب تقدمي (PWA)، بواجهة عربية من اليمين إلى اليسار.

## تشغيل سهل على Windows
1. فك ضغط الملف ZIP.
2. افتح مجلد `moaadh-ai-education`.
3. انقر مرتين على `شغّل_التطبيق.bat`.
4. إذا لم يفتح المتصفح تلقائيًا، افتح `http://localhost:8000`.
5. اترك نافذة التشغيل مفتوحة أثناء استخدام التطبيق.

يتطلب التشغيل المحلي Python 3. لا تفتح `index.html` بالنقر المزدوج؛ شغّله عبر الملف أعلاه.

## حالة النسخة
- اسم التطبيق واسم التثبيت: **معاذ AI للتعليم**.
- الاسم التعريفي: **إعداد وتطوير معاذ علي**.
- واجهة عربية، بحث وفلاتر للطور والسنة والمادة.
- ملفات الفروض والاختبارات فارغة عمدًا إلى أن تتم إضافة محتوى حقيقي موثّق.
- لا توجد حاليًا لوحة إدارة أو قاعدة بيانات أو حسابات مستخدمين.
- هذه نسخة ويب قابلة للتثبيت من المتصفح بعد نشرها عبر HTTPS، وليست ملف APK أصليًا.

## نشر مجاني لاحقًا
يمكن نشر الملفات الثابتة عبر GitHub Pages في مستودع عام. انتبه: الملفات في المستودع العام ستكون متاحة للناس؛ لا ترفع مفاتيح سرية أو بيانات شخصية. بعد النشر افتح رابط HTTPS في Chrome على Android، ثم اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» إن ظهر الخيار.

## المحتوى التعليمي
أضف فقط ملفات لديك إذن بنشرها، وتحقق من المصدر والحلول قبل عرضها. لا تنسب أسئلة مولّدة أو غير متحققة إلى وزارة التربية أو إلى امتحان رسمي.
